# characters

Put character sheets here, one per file, if you keep them.

Only the `verify_citations` and `prose_check` project reports read this
directory, and both are off by default. `verify_citations` checks that
quotations in a sheet actually appear in the manuscript, which catches a sheet
written from memory that reads exactly like the book but was never in it.

Point somewhere else with `characters_dir` in `config.json`. Nothing here is
required.
